# Activity 6 – Library Management System

## Objective
To develop a Library Management System using Java Object-Oriented Programming concepts.

## Features
1. Add new books.
2. Display available books.
3. Search for a book.
4. Issue a book.
5. Return a book.

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Conclusion
This project demonstrates the use of Java OOP concepts to manage library operations efficiently. It helps in understanding how real-world applications can be developed using object-oriented programming.
