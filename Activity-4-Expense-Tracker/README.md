# Activity 4: Advanced Java Application - Daily Expense Tracker

## Objective
To develop a Java application using exception handling, multithreading and collections.

## Project Name
Daily Expense Tracker

## Programming Language
Java

## Concepts Used

### 1. Exception Handling
Used try-catch blocks to handle invalid amounts, invalid expense details and file errors.

### 2. Multithreading
Used SwingWorker to load expense records in the background without freezing the application interface.

### 3. Collections
Used ArrayList to store and manage multiple expense records dynamically.

## Features
- Add daily expenses
- View expense history
- Calculate total expenses
- Delete selected expenses
- Save expense records in a file

## Learning Outcome
Learned how to use exception handling, multithreading and Java collections in a practical application.
