# Activity 4 – Advanced Java Application

## Project Name
Daily Expense Tracker

## Objective
To develop a Java application using exception handling, multithreading, and collections.

## Concepts Used
1. **Exception Handling:** Handles errors using try-catch.
2. **Multithreading:** Performs background tasks using SwingWorker.
3. **Collections:** Uses ArrayList to store expense records.
4. **OOP:** Uses classes and objects.

## Features
- Add expenses
- View expenses
- Calculate total expenses
- Delete expenses
- Save expense records

## Conclusion
This activity helps us understand advanced Java concepts by developing a practical Daily Expense Tracker application.
