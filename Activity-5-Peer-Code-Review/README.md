# Activity 5 – Peer Code Review

## Objective
To review Java programs written by a peer, identify possible improvements, and provide suggestions through GitHub.

## Repository Reviewed
Tanvi's Advanced Java OOP Activities

GitHub Link: https://github.com/TANVI1027/Advanced-Java-OOP-Activities

## Code Review and Suggestions

### 1. BankingSystem.java
- Make account variables private using encapsulation.
- Add validation to prevent negative deposit amounts.
- Use proper exception handling for invalid transactions.

### 2. EmployeeManagement.java
- Use private data members.
- Add salary validation.
- Use getter and setter methods to access employee details.

### 3. CustomExceptionDemo.java
- Accept age through user input.
- Display meaningful exception messages.
- Handle invalid input properly.
